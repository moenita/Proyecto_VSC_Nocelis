## [1.0.0] - 2026-08-20

### Added

- Initial release of Nocelis Theme.
- Nocelis Dark theme.
- Nocelis Light theme.
- Custom Nocelis color palette.
- Electric blue interface accents and borders.
- Custom syntax highlighting.
- Custom colors for keywords, types, variables, functions, strings, numbers, and comments.
- Semantic highlighting for variables and parameters.
- Customized Activity Bar, Sidebar, Status Bar, Title Bar, Tabs, and Editor.
- Dark and light interface variants.

### Design

- Nocelis Dark uses a dark navy editor with electric blue accents.
- Nocelis Light uses a soft light interface with pastel blue accents.
- Purple is used for variables.
- Red is used for types and numeric values.
- Cyan is used for functions and methods.
- White/light text is used for standard code elements.
